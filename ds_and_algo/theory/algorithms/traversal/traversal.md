# About

A Traversal is an algorithm that visits every vertex (node) and edge (connection) in a Tree or a Graph. Examples of graph traversal algorithms include: [BFS](./bfs.md), [DFS](./dfs.md), [A\*](../shortest_path/a_star.md), [Dijkstra](../shortest_path/dijkstra.md), and [Bellman Ford](../shortest_path/bellman_ford.md).

# Use Cases

- Use a traversal to check whether a [Binary Search Tree](../../data_structures/trees/binary_search_tree.md) is valid or not.
- Use a traversal when operations are required to be applied to every single node of a Tree or Graph.
- Use a traversal when operations/properties are required to be applied/added to every single item in a graph-like database. For example, adding columns to items.
