# About

Unlike [Bellman Ford](./bellman_ford.md), Dijkstra only works in Graphs with non-negative weight edges, however, it is more efficient than Bellman Ford which has a time complexity of $O(n^2)$.

# Use Cases

Dijkstra is used to find the shortest path from the source node (vertex) to all graph vertices (neighboring nodes) in graphs with `positive weight edges` (connections).

Note: Dijkstra is used in google maps along with A\*.
