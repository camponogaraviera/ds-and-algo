# About

Unlike [Dijkstra](./dijkstra.md), Bellman Ford works in graphs with negative weight edges, however, it has a worse time complexity.

# Use Cases

Bellman Ford is used to find the shortest path from the source node (vertex) to all graph vertices (neighboring nodes) in graphs with `negative weight edges` (connections).
