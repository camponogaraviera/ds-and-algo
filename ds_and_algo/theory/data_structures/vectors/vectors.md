# About

A Vector generally refers to a dynamic array (e.g., in C++) that can grow and shrink dynamically in length (such as linked lists), and its internal structure usually resizes automatically when more space is needed.

Note: while `JavaScript` does not have a native vector type as seen in other programming languages (e.g., C++ or Java), the concept of a Vector can be understood as a dynamic array-like data structure.
