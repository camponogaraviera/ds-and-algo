# About

This course provides a strong foundation in data structures and algorithms for problem-solving and technical interviews in Python and Modern JavaScript (ES6+).

It emphasizes maintainable implementations, production code quality, and engineering best practices. Including interview questions and LeetCode problems categorized by DSA patterns.

By the end of this course, you should have a strong conceptual understanding of data structures and algorithms, the ability to implement them from scratch, to recognize recurring problem-solving patterns, and the engineering discipline to write clear, maintainable implementations.

- Foundations
  - Comprehensive theoretical foundations of data structures and algorithms with real-world use cases. [References](#ref) are provided throughout the chapters.
  - Production implementations in Python and modern JavaScript (ES6+).
  - Big O time and space complexity analysis.
  - DSA patterns to solve LeetCode problems.

- Code Quality
  - Object-oriented implementations with DRY design principles for code maintainability.
  - Input validation and edge-case handling.
  - Modern Python type hints with built-in generics.
  - JSDoc and Modern Google-style docstrings.

- Engineering Workflow
  - Pre-commit hooks for automated local checks.
  - GitHub Actions for continuous linting and formatting on every push and pull request.
  - SonarQube for automated static analysis and code-quality inspection.

<!-- #region JS Dependencies -->
<details>
  <summary><h1 id="js_dependencies">6. Install JS Dependencies</h1></summary>

1. Install [Node Version Manager](https://github.com/nvm-sh/nvm) (NVM):

```bash
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
```

2. Install and use the latest LTS release version of Node.js (recommended):

```bash
nvm install --lts && nvm use --lts && node -v
```

3. Install Corepack

```bash
npm install -g corepack
```

4. Install [modern Yarn](https://yarnpkg.com/getting-started/install) V2+ with Corepack (shipped by default with Node.js):

```bash
corepack enable && yarn set version stable && yarn install && yarn -v
```

5. Install package dependencies listed in the `package.json` file:

```bash
yarn
```

</details>

Lint and format your code before opening a pull request:

```bash
uv run pre-commit run --all-files
```

Or manually:
